## Free / Pro recommendation and WordPress policy

This is a proposed product split, not implemented licensing or a WordPress directory approval.

| Keep in Free | Suitable for a separate future Pro add-on |
|---|---|
| Simple setup, manual issuance, verification/status/privacy, recipient portal, basic local CSV, basic stock designs, reliable local PDF/PNG/JPEG and usable backup/recovery | Approved provider/LMS/commerce connectors, advanced automation/rules, advanced analytics, remote cloud backup, team operations and premium design packs |

Keep core usability, privacy, security repairs and trustworthy local recovery available without payment. Do not ship paid/trial locks around local code in the WordPress.org plugin, or quota-lock included functionality. A paid external SaaS is a distinct service; a remote license check merely unlocking included local code is not that service model. Premium add-on distribution should stay separate from the directory plugin's installer; external data transmission requires explicit informed opt-in, and upsells should remain contextual. Sources checked: [official detailed guidelines](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/) and [official common issues](https://developer.wordpress.org/plugins/wordpress-org/common-issues/).

Current `DomainFeatureGate` review/admin-preview flags and renderer acceptance gate are engineering/release safeguards, not Pro licensing. CSS names containing “premium” are not evidence of a implemented paid tier. No feature was moved behind a new paywall in this pass.
