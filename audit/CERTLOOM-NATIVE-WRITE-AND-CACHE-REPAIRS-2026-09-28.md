# Native writes and backup consistency repairs — 28 September 2026

Native repository commands now hold maintenance admission for their whole transaction, nested commands use checked savepoints, and core WordPress cannot automatically replay protected SQL after losing its database session. Import/restore review and recovery-state decisions now read actual database values. Further live testing also reproduced and repaired three legacy-backup failures: warmed caches concealed concurrent changes, non-admin requests lacked a required WordPress file helper, and restore validation rejected Certloom's own credential-visibility field.

This continues the [recovery fence report](CERTLOOM-RECOVERY-FENCE-REPAIRS-2026-09-28.md). It is a development checkpoint, not complete recovery, renderer acceptance, or certification of every UI workflow.
