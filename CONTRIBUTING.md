# Contributing to CertVerify

CertVerify is maintained by Ecapla. Please open an issue before proposing substantial changes.

## Development rules

- Preserve backward compatibility and the plugin update identity.
- Follow WordPress Coding Standards and the WordPress.org Plugin Guidelines.
- Sanitize input, escape output, and protect state-changing actions with capabilities and nonces.
- Do not add telemetry, external requests, tracking, or remote code without explicit approval and documented consent.
- Increment the plugin version for every release.

## Validation

Before submitting a change, verify PHP and JavaScript syntax, package structure, upgrade behavior, frontend rendering, Elementor integration, block behavior, import/export, and restore safety.
